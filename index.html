PixelBrief Extension

This is a Chrome Extension built with React, Vite, and Tailwind CSS.

Installation Steps:

  1. Build the extension: npm run build
  2. Open Chrome and navigate to: chrome://extensions
  3. Turn on Developer Mode (top right switch).
  4. Click Load unpacked (top left button).
  5. Select the dist folder generated in this project directory.

Press Ctrl+Shift+M (Cmd+Shift+M on Mac) on any regular web page to toggle annotations!
